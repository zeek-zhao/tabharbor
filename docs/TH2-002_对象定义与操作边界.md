# TH2-002 · 窗口 / 分组 / 标签：定义、边界与操作（统一口径）

> 本文件是 TabHarbor 的**统一口径**：需求文档（`docs/TH2-003_*`）、实现（`src/core/*`）、
> 测试（`features/*.feature`、`tests/e2e-chromium.mjs`）对这三类对象的措辞一律以此为准。
> 版本：v1.0（N2 / m10950 建立）。UI 事实源：`prototypes/tabharbor.html`。

## 1. 一句话模型

浏览器真实窗口 → 分组（可嵌套）→ 标签（网页），整理为一棵可拖拽树。
双模式（独立窗口 / 侧边栏）共享同一份数据，与浏览器严格实时同步。

## 2. L1 层级与类型识别（固化规则）

```
L1（顶层）        window 窗口   parentId = null      —— 一条「浏览器窗口」分支的根
L1 内（第二层起） group  分组   parentId → window 或父 group —— 可嵌套容器
叶子              tab    标签   parentId → group 或（FR-024）window —— 一个网页
```

**识别依据唯一**：`kind` 字段 + 所在数组（`windows` / `groups` / `tabs`）的归属关系。
实现入口：`src/core/levels.js`（`LEVEL`、`kindByMembership`、`kindConsistent`、
`isTopLevel`、`conversionRule`）。

**禁止**：以 `title`（名称）或 `url`（链接）判定节点类型或身份。
- 标签身份 = 独立算法哈希 ID（`model.newId`，FNV-1a）；浏览器身份 = `tabId`（优先），URL 仅兜底。
- 同名、同链接的两个标签是两个独立节点，不共享打开态 / 关闭行为 / 回收站条目。

## 3. 三类对象定义与边界

### 3.1 窗口（window）

| 项 | 内容 |
| --- | --- |
| 定义 | L1 顶层容器，对应一个浏览器窗口的整理视图；`parentId` 恒为 `null`。 |
| 边界 | 只能是根；不能成为别的窗口或分组的子节点（合并/互转除外——合并会移除源窗口，互转会改 kind）。 |
| 数据 | `windows[]`；字段 `id`（哈希）、`kind:"window"`、`title`、`collapsed`。 |
| 操作 | 新建、重命名、折叠/展开、整窗复制、导出该窗、删除到回收站（含子树）、拖到另一窗口=合并、拖到窗口行=升/降判定、拖到分组行=转为分组、置顶（仅独立窗口页，Document PiP）、行内复制按钮常显。 |
| 前端相关 | `当前浏览器窗口` 是特殊系统窗口（FR-024），由启动归类自动维护，其标签可直挂窗口下。 |

### 3.2 分组（group）

| 项 | 内容 |
| --- | --- |
| 定义 | L1 内的容器，可嵌套（`parentId` 指向窗口或父分组），代表一组标签。 |
| 边界 | 不能是 L1 顶层（顶层必须是窗口）；不能含窗口作为子节点（窗口必须先转为分组）；禁止拖入自身后代形成环。 |
| 数据 | `groups[]`；字段 `id`、`kind:"group"`、`title`、`parentId`、`collapsed`、`note`。 |
| 操作 | 新建（窗内/子组）、重命名、备注、折叠/展开、整组打开、关闭整组已打开标签、整组复制、拖到另一组=子组、拖到窗口行=转为窗口、拖到分组行=改挂、删除到回收站（含子树）、行内复制按钮常显。 |

### 3.3 标签 / 网页（tab / leaf）

| 项 | 内容 |
| --- | --- |
| 定义 | 叶子，对应一个网页；`parentId` 指向分组或（FR-024）窗口。 |
| 边界 | 不能再有子节点；身份不由名称或链接决定；同一链接可开 N 个独立标签。 |
| 数据 | `tabs[]`；字段 `id`、`kind:"tab"`、`title`、`url`、`parentId`、`note`、`tabId`（浏览器标签页 ID，R1 固化）。 |
| 操作 | 双击/行内打开、复制、行内关闭（只关当前一个）、备注、拖到另一标签后=排序、拖入分组/窗口=迁移、删除到回收站、前缀显示浏览器 favicon（N3）。打开态 / 图标为派生态，不入库。 |

## 4. 操作矩阵（统一口径）

| 操作 | 窗口 | 分组 | 标签 |
| --- | --- | --- | --- |
| 打开 | 打开窗内全部（组级入口） | 打开整组 | 双击 / 行内打开 |
| 关闭 | 关闭窗内已开 | 关闭整组已开 | 行内 X（仅已开显示，只关一个） |
| 复制 | 整窗 | 整组 | 单条 |
| 删除 | 到回收站（含子树） | 到回收站（含子树） | 到回收站 |
| 折叠 | ✓ | ✓ | — |
| 拖拽 | 合并到窗口 / 转为分组 | 转为窗口 / 改挂 / 子组 | 排序 / 迁移 |
| 置顶 | ✓（独立窗口页 PiP） | — | — |
| favicon 前缀 | — | — | ✓ |

## 5. 互转判定（N1，详见 skill）

1. group → window：源必须是分组（L2，未处于 L1 顶层），拖到窗口行 → `turnGroupIntoWindow`，
   id 与子树不变，仅改 `kind` / `parentId=null` / 数组归属。
2. window → group：源必须是窗口（L1），拖到分组行 → `turnWindowIntoGroup`，目标不得位于源子树内
   （沿 `parentId` 上溯检测），id 与子树不变。
3. 判定入口 `conversionRule(m, srcId, targetKind, targetId)` 返回 `{op, reason}`；
   `op ∈ {group→window, window→group, null}`；UI 与 model 共用该规则，不得各自实现。
