# 壁纸来源评估与画廊口径（wallpaper-assessment）

> 2026-11-26 任务 6。本文记录「精选壁纸画廊」的选型结论与在线图库评估。
> 状态口径：本文描述的功能以 `docs/requirements/requirements-status.md` 为准；未真机验证前一律写「已实现」，不写「已验证」。

## 1. 结论摘要

| 项 | 结论 |
| --- | --- |
| 第一版内置壁纸 | **原创 CSS 渐变/图案 10 张**，零版权风险、完全离线，随包发布 |
| 元数据 | 每张含 `artist` / `source` / `sourceUrl` / `license`（CC0），选中后写入配置并可导出 |
| 在线图库 | **仅评估，不默认接入、不实现** |
| booru 类站点 | **不接入**（版权与内容合规风险不可控） |
| 远程图片 | 仅用户主动输入的 https 链接；8 秒超时失败回退内置渐变 |

## 2. 为什么第一版用原创渐变

- 扩展打包第三方图片需逐张核对许可（CC0/CC-BY 及署名义务）、保留来源与作者信息，且图片体积会使包膨胀、影响审核与加载。
- 原创 CSS 渐变/图案：作者、来源、许可清晰（TabHarbor 原创 / 内置精选 / CC0），零出站、零版权争议、零CSP 图片域名问题。
- 因此第一版画廊展示 10 张原创壁纸，缩略图即 CSS 渐变本身，不发起任何网络请求。

## 3. 在线图库评估（不接入）

| 来源 | 内容尺度 | 画幅 | 许可/署名 | 接入评估 |
| --- | --- | --- | --- | --- |
| Wallhaven | anime / SFW 分类可筛选 | 16:9 可筛选 | 图片许可各异，作者归属需逐张核对 | **不接入**：需逐图核对许可与署名，且引入内容审核与出站风险 |
| Nekos.best | 动漫图、尺度参差 | 画幅不一 | 许可与作者信息不完整 | **不接入**：仅备选评估，版权元数据不足 |
| booru 类站点 | 用户上传、尺度与版权混杂 | 不一 | 署名/许可普遍缺失 | **明确不接入**：版权与内容合规风险不可控 |

评估结论：在线图库需新增主机权限、逐图版权核对、内容过滤与超时回退，超出本轮「零出站红线」口径。**本轮不接入**；若后续产品要求接入，应作为独立口径变更，走红线评审并补齐署名/许可链路。

## 4. 远程图片（用户主动输入）口径

- 仅接受用户手动粘贴的 https 图片链接（`normalizeWallpaperUrl` 校验，拒绝 http 明文与一切伪协议及注入字符）。
- 链接仅存本机，不上传；可能暴露网络环境，隐私说明见 `docs/PRIVACY.md`。
- 加载：8 秒未完成或加载失败即回退内置渐变（避免长时空白与悬挂请求）。
- 远程模式清空本地图片元信息；本地图片模式清空远程 sourceUrl，二者二选一。
- 用户可填 `source_url` / `artist` 记录原图来源与作者，随配置导出。

## 5. 真机待验证项

- 远程图片的 CSP：扩展主页对 `img-src` 的限制需真机确认；若拦截则依赖失败回退渐变，不影响可用性。
- 本项标注「待验证」而非「已验证」，证据待 G1 签核人真机截图确认。
