## 3. 完整用户指南

### 3.1 安装 / 加载（开发者模式）
1. 下载仓库 ZIP 或 `git clone`；Chrome → `chrome://extensions` → 开发者模式 →「加载已解压的扩展程序」→ 选择 `src/` 目录。
2. 点击工具栏 TabHarbor 图标 → 按设置「打开方式」打开独立窗口或侧边栏（默认侧边栏）。
3. 首次启动：若浏览器有已打开网页，启动归类会把命中的标签挂到「当前浏览器窗口」对应节点（严格实时同步，FR-005）。

### 3.2 日常操作
- **树操作**：单击窗口/分组行 = 展开收起；单击标签 = 选中；双击标签 = 打开网页（新标签插到当前激活网页右侧）；拖拽 = 排序 / 移入分组 / 窗口拖到窗口内降级为子组（**无跨窗口合并**）；行内 ⧉ = 复制整窗/整组/单标签；行内 ✕ = 关闭已打开标签；删除入回收站同步关闭对应网页。
- **右键菜单**：标签（仅「删除到回收站」；复制走行内 ⧉、重命名走行尾铅笔、备注入口已移除）、分组（打开整组 / 关闭整组已打开标签 / 删除整组到回收站）、窗口（打开窗内全部标签 / 关闭窗内已打开标签 / 删除整窗到回收站）；添加标签 / 分组走行尾加号，改名走行尾铅笔。
- **快捷键**：↑↓ 选择、Enter 打开、Delete 移入回收站、Ctrl+C 复制、Ctrl+L 定位、Ctrl+E 展收全部、Ctrl+Shift+L 链接显隐、Ctrl+O 打开整组、Ctrl+D 主题、Ctrl+Backspace 回收站弹窗（完整表见弹窗）。
- **搜索与定位**：顶部输入框实时过滤（保留祖先链）；⌖ 定位到第一个已打开标签。
- **回收站**：🗑 弹窗内恢复（回原父，父已删则落首个可用分组）或彻底删除；角标显示条目数。
- **统计底栏**：窗口 / 分组 / 标签 / 已打开 四项实时刷新。

### 3.3 异常恢复
1. 误删 → 回收站恢复（详见 `docs/M3-导入导出与备份演练指南.md` §3.4）。
2. 树数据损坏 / 误导入 → 恢复最近的本地快照（备份列表按时间倒序）。
3. 无快照 → 导入事先导出的 JSON/HTML 备份文件。
4. 扩展重装后数据丢失 → `chrome.storage.local` 随浏览器档案存续；跨设备迁移用导出 JSON。

## 5. 隐私 / 权限 / 发布门禁记录

| 项 | 现状 |
|---|---|
| 权限 | 仅 7 项必需：tabs / storage / sidePanel / contextMenus / alarms / commands / downloads；可选 host 仅 `https://api.github.com/*`（用户显式授权后仅 backup 使用） |
| 零出站 | C11/C12 门禁静态扫描：fetch/XHR 仅允许 import-export.js，URL 仅 api.github.com；测试全程 mock，无真实远程写入 |
| 书签 API | C05 门禁：任何 `bookmarks.*` 调用 0 命中；不监听书签变更 |
| 浏览历史 | 不申请 history 权限、不读取/删除浏览历史 |
| 敏感信息 | compliance 门禁扫描 GitHub token 等不入库；样例 URL 均为 example.com |
| 版本 | 预览候选 manifest 0.3.0.1（`version_name` 0.3 Preview 1）；发布节奏 = 0.3 预览候选 → PR 合回 `main` → 正式版 `v0.3.0` → tag → Release；立项规划的 v1.0.0 未发布、不作承诺 |
