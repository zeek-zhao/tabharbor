# TabHarbor 隐私政策（Chrome Web Store 发布稿）

> 本文件用于 Chrome Web Store 上架的「隐私政策 URL」与权限理由披露。TabHarbor 是一款 Chrome MV3 标签管理扩展，把浏览器真实窗口 / 分组 / 标签整理为一棵可拖拽的树，提供打开 / 关闭 / 聚焦、搜索、复制、导入导出与本地或加密备份。
>
> **待办**：正式上架前需将本政策发布为公开可访问的 URL（如 GitHub Pages / Release 页附件），并在 Dashboard 填写该链接；上架材料清单见 `docs/release/v0.3.0.md`。

## 1. 收集与处理的信息

扩展在**本机**读取并处理以下浏览器数据，用于构建和维护标签树：

- 标签标题、URL、标签 ID、favicon 图标；
- 用户自建的窗口 / 分组 / 标签结构与备注；
- 回收站条目；
- 外观、打开方式、复制内容与格式、上次位置等设置；
- 扩展内部主页配置（搜索引擎、自定义引擎、常用网址、壁纸设置、离线装饰开关与本地便签、外链音乐链接、天气城市/坐标）；
- **仅当用户主动在壁纸设置中输入时**：用户填写的 https 图片链接（仅存本机配置，用于主页背景）；精选壁纸画廊为随包发布的原创 CC0 渐变，不含远程图片、不发起请求；
- **仅当用户在壁纸设置中主动点击「加载候选」时**：向 Wallhaven（anime/SFW/16:9）或 Nekos.best 发起一次图源查询（可选主机权限，见权限表），返回缩略图候选供用户挑选；不自动轮询、不预取；
- **仅当用户主动启用 GitHub Gist 备份时**：用户填写的 GitHub Personal Access Token。

扩展**不**读取浏览历史、不监听浏览器书签变更、不收集Cookies、不注入网页脚本、不追踪用户行为。

## 2. 使用目的

以上信息仅用于提供标签整理、打开 / 关闭 / 聚焦、搜索、复制、导入导出，以及本地或加密备份 / 恢复功能。不做个性化广告、行为画像，不销售或共享给第三方。

## 3. 存储位置与保留

- 书签树、回收站、设置、主页配置、本地快照与 Token 默认保存在 **Chrome 本地扩展存储**，不上传（GitHub 备份除外）。
- 备份密码**不落盘、不写入备份文件、不写日志、不做会话暂存**：每次加密 / 解密由用户临时输入，用完即清。
- 本地加密快照下载到用户设备；GitHub 备份是加密完整快照（含书签树 + 回收站 + 设置 + 主页配置）。
- 用户可随时在扩展内导出数据、清空回收站；卸载扩展后本地扩展存储按 Chrome 机制清理。

## 4. 第三方传输

**只有**用户主动配置并授权 GitHub 备份后，加密快照才会发送到 `api.github.com`，用于创建或更新用户的私有 Gist。除此之外不向任何外部服务发送标签数据。撤销 `api.github.com` 可选主机权限或关闭远端备份即可停止该传输。

**主页壁纸的远程图片链接**：若用户在壁纸设置中主动输入 https 图片地址，浏览器会在打开内部主页时向该图片地址发起一次图片资源请求以显示背景。这不是扩展代码主动发送标签数据（不是 fetch / XHR），但该图片服务可能记录访问、暴露网络环境信息；扩展不保证第三方图片的可用性与内容安全。用户可随时清除链接并回退到内置渐变。此例外是否正式纳入红线白名单待产品/用户拍板。

**外链音乐播放器（阶段 1）**：若用户主动粘贴公开音乐链接（SoundCloud / Spotify / Internet Archive / 网易云外链 / 自定义），主页会以嵌入式 iframe 显示对应平台的公开播放器。嵌入后浏览器会向该平台发起页面 / 图片 / 音频资源请求，平台可能据此记录访问；扩展**不读取用户的商业平台账号、不抓取受版权保护的音频直链、不登录任何第三方服务**。链接仅保存 `sourceUrl` / `embedUrl` / 标题 / 来源域名于本机配置，不保存第三方 Cookie 或登录态；默认不自动播放，加载失败可改为"在新标签打开"。是否正式纳入出站白名单待产品/用户拍板。

**天气卡片**：默认手动输入城市、不主动请求地理位置；仅在用户点击"使用当前位置"后调用一次定位（`geolocation`，用户显式触发，不后台监听），并仅在主页打开时向 Open-Meteo（`api.open-meteo.com` / `geocoding-api.open-meteo.com`）请求一次天气数据（不后台轮询）。离线或失败时隐藏卡片并显示 Open-Meteo 署名。相关出站域名白名单见约束文档；是否正式纳入出站白名单待产品/用户拍板。

**离线装饰与本地便签**：时钟、日期、问候语、快捷操作条、快捷键提示卡与本地便签均为纯本地渲染与本机存储，不出站、不上传、不申请额外权限。

**精选壁纸画廊**：随包发布的 10 张原创 CC0 渐变，缩略图即 CSS 本身，不加载远程图片、不发起网络请求；选中后作者/来源/许可随配置存于本机并可导出。

**在线壁纸图源（2026-11-27 起可选接入）**：用户点击「加载候选」后，扩展向 Wallhaven API（仅 anime 分类、SFW 过滤、16:9 宽高比）或 Nekos.best 发起一次查询，展示缩略图候选；用户选中后原图地址经安全校验（仅 https、拒绝伪协议与注入字符）存入本机配置。查询与后续图片展示会让图源服务记录访问、暴露网络环境信息；SFW 过滤依赖图源标注，扩展不保证第三方内容。booru 类站点不接入。详见 `docs/operations/wallpaper-assessment.md`。

## 5. 认证信息

GitHub Token 属于认证信息，以明文保存在本机扩展存储（界面已明确提示）。请勿在公用设备使用，不要把 Token 粘贴到 issue、日志或截图。远端 Gist 需用户在 GitHub 侧自行删除。

## 6. 权限说明

| 权限 | 理由 |
| --- | --- |
| `tabs` | 读取当前浏览器标签以建立窗口 / 分组 / 标签树，并按用户操作打开、关闭、聚焦或移动标签、派生打开态。 |
| `storage` | 在本机保存标签结构、回收站、外观 / 复制 / 备份设置与主页配置。 |
| `sidePanel` | 在浏览器侧边栏展示标签树。 |
| `contextMenus` | 在工具栏图标右键菜单提供「打开侧边栏」入口。 |
| `alarms` | GitHub Gist 定时备份；触发时用已保存 Token 重新获取 GitHub 登录名派生加密密码（密码不落盘），Token 缺失不发网络请求。 |
| `commands` | 支持键盘快捷键唤起扩展与常用树操作。 |
| `downloads` | 保存用户主动导出的书签文件或加密备份到本地。 |
| `geolocation` | 扩展具备定位能力；仅当用户在天气卡片主动点击"使用当前位置"时调用一次 `getCurrentPosition`（浏览器弹出原生授权），不后台监听、不在未授权时请求。 |
| 可选主机 `https://api.github.com/*` | 用户配置 GitHub 备份并授权后，创建 / 更新私有 Gist，不访问其他站点。 |
| 可选主机 `https://wallhaven.cc/*`、`https://w.wallhaven.cc/*`、`https://nekos.best/*` | 用户在壁纸设置主动点击「加载候选」后向图源查询一次并加载缩略图/原图；不自动轮询。 |
| 可选主机 `https://api.open-meteo.com/*`、`https://geocoding-api.open-meteo.com/*` | 仅天气卡片启用且主页打开时，按用户配置请求一次天气/地名数据；不后台轮询。 |

## 7. 数据类别（Dashboard 勾选建议）

- Web history / Website content（标签标题、URL、favicon）；
- Authentication information（仅启用 GitHub Token 功能时）。

不勾选位置、健康、金融、个人通信等无关类别。

## 8. 用户控制与联系

用户可导出数据、清空回收站、撤销主机权限、卸载扩展。对本政策或数据处理有疑问，请通过项目 issue 页反馈（扩展页脚 GitHub 图标）。
