# 样例目录

- `datasets/tabharbor-sample.json`：扩展完整 JSON 模型样例，可经「导入数据」自动嗅探导入。
- `datasets/tabharbor-sample.html`：标准 Netscape Bookmark HTML 样例，可经「导入数据」导入。
- 每个数据集包含至少一个窗口、多个分组、每组多个标签页；所有链接都是 `example.com` 占位地址。
- 使用步骤、安全提示、演练流程与能力边界见 [`../docs/operations/sample-data.md`](../docs/operations/sample-data.md)；
  导入导出与备份规则见 [`../docs/operations/backup-guide.md`](../docs/operations/backup-guide.md)。

> 导入操作可能覆盖主页配置 / 恢复加密备份，请使用专门的 Chrome 测试 Profile。样例不访问 Chrome 书签 API，不启用 GitHub 备份，也不含凭据。
