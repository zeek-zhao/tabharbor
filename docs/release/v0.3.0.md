# TabHarbor v0.3.0 正式版 Release 说明

> 分支：`release/v0.3.0-preview`（发布基线 = 合入 `main` 的正式提交）；tag `v0.3.0`。
> 版本：`package.json` `0.3.0`；`manifest.json` `version: 0.3.0`。
> 产物：`tabharbor-v0.3.0.zip`（仅 `src/` 运行时文件，manifest 位于 ZIP 根）。

## 1. 相对 v0.2.0 的主要变更

- **新标签相邻插入**：双击打开 / 容器加号新建主页标签 / 批量打开，新标签插到所属真实窗口**激活网页右侧**（index = 锚点+1 且带 openerTabId）；批量打开每窗口从锚点右侧连续递增、保持树内顺序；无锚点（新建窗口/游离标签）不指定索引。
- **删除到回收站同步关闭网页**：叶子删除先按 tabId 关闭真实标签；容器删除关闭整个子树；关闭失败不入回收站并提示；回收站条目清洗 tabId/open/windowId，恢复后为离线整理数据。
- **右键菜单收敛**：叶子仅「删除到回收站」；组/窗各 3 项；复制走行内按钮、重命名走行尾铅笔。
- **PiP 宿主化**：PiP 与主页面共享同一套控制器/面板绑定；设置、回收站、编辑、新建、备份、导入导出可在 PiP 内操作；say/toast/主题广播所有宿主。
- **定位加固**：`locateActiveTab` tabId-only；定位前同步真实快照补游离标签；内部页明确提示。
- **打开态修复**：存活集合按 tabId 不按 URL 过滤；加载期 loading/complete/url 去抖刷新，消除「先亮后变灰」。
- **反馈入口**：页脚指南图标右侧，三端一致。
- **加密备份**：本地/GitHub 两步卡片流程；加密信封纳入导入嗅探；恢复失败四分类提示。
- **CI/release 工作流**：补 contrast 门禁；release 前补真机 E2E。
- **文档体系**：`docs/requirements|architecture|testing|release|operations` 当前态文档 + `docs/history/resolved-issues.md` 教训记录。
