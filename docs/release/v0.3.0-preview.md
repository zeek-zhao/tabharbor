# TabHarbor v0.3.0-preview.1 预览版发布说明

> 分支：`release/v0.3.0-preview`（当前基线提交 `bcc1969`）。
> 版本：`package.json` `0.3.0-preview.1`；`manifest.json` `version: 0.3.0.1` + `version_name: 0.3 Preview 1`。
> 产物：`tabharbor-v0.3.0-preview.1.zip`（仅 `src/` 运行时文件，manifest 位于 ZIP 根）。GitHub Release 标记 **Prerelease**。

## 1. 相对 v0.2.0 的主要变更

- **新标签相邻插入**：双击打开 / 容器加号新建主页标签 / 批量打开，新标签插到所属真实窗口**激活网页右侧**（index = 锚点+1 且带 openerTabId）；批量打开每窗口从锚点右侧连续递增、保持树内顺序；无锚点（新建窗口/游离标签）不指定索引。
- **删除到回收站同步关闭网页**（2026-11-24 口径反转，取代旧 FR-018）：叶子删除先按 tabId 关闭真实标签；容器删除关闭整个子树；关闭失败不入回收站并提示；回收站条目清洗 tabId/open/windowId，恢复后为离线整理数据。
- **右键菜单收敛**：叶子仅「删除到回收站」；组/窗各 3 项；复制走行内按钮、重命名走行尾铅笔。
- **PiP 宿主化**：PiP 与主页面共享同一套控制器/面板绑定；设置、回收站、编辑、新建、备份、导入导出可在 PiP 内操作；say/toast/主题广播所有宿主。
- **定位加固**：`locateActiveTab` tabId-only；定位前同步真实快照补游离标签；内部页明确提示。
- **打开态修复**：存活集合按 tabId 不按 URL 过滤；加载期 loading/complete/url 去抖刷新，消除「先亮后变灰」。
- **反馈入口**：页脚指南图标右侧，三端一致。
- **加密备份**：本地/GitHub 两步卡片流程；加密信封纳入导入嗅探；恢复失败四分类提示。
- **CI/release 工作流**：补 contrast 门禁；release 前补真机 E2E。

## 2. 已知限制

- 全屏卡片视图**待实现**（点击提示「待实现」），发布文案不承诺。
- GitHub 备份远端写入全部 mock 验证，真实线上 Token 演练留待正式版前。
- PiP 内深度配置（GitHub 授权等受浏览器约束的弹窗）建议在独立窗口操作。
- 浏览器原生书签一键导入为红线废弃（需 bookmarks 权限）；替代路径：导出 HTML 后手动导入。
