# 日常使用指南（user-guide）

> 面向使用 / 验收人员：加载、树操作、打开 / 关闭 / 复制 / 重命名、搜索定位、快捷键、回收站、主题、PiP。
> 功能是否已实现以 `docs/requirements/requirements-status.md` 为准；备份与导入导出详见 `docs/operations/backup-guide.md`。

## 1. 安装与加载

1. Release 页下载 `tabharbor-vX.Y.Z.zip` 解压（开发调试可直接用仓库 `src/`）。
2. Chrome 打开 `chrome://extensions` → 开发者模式 →「加载已解压的扩展程序」→ 选择 `src/` 目录。
3. 点击工具栏 TabHarbor 图标 → 按设置「打开方式」打开独立窗口或侧边栏（默认侧边栏）；
   快捷键 `Alt+Shift+B` 侧边栏、`Alt+Shift+W` 独立窗口。
4. 首次启动：若浏览器有已打开网页，启动归类会把命中的标签挂到对应窗口节点（严格实时同步）。

## 2. 树操作

- **折叠 / 展开**：单击窗口 / 分组行；折叠态显示直接子节点计数。
- **选中**：单击标签行。
- **打开网页**：双击标签（或 Enter / 右键打开）；新标签插到当前激活网页**右侧**（相邻插入）。
  已打开的标签双击只聚焦，不重复开。
- **新建**：行尾加号新建标签 / 子分组；容器加号在主页内新建标签。
- **复制**：行内 ⧉ 复制整窗 / 整组 / 单标签（Markdown 或纯文本，按设置）。
- **重命名**：行尾铅笔；**关闭已开标签**：行内 ✕（仅已开显示，只关一个）。
- **删除**：右键菜单或 Delete 键 → 移入回收站并**同步关闭对应网页**（详见第 6 节）。
- **拖拽**：排序 / 移入分组 / 分组↔窗口互转（保持 id 与子树不变）；拖拽到折叠分组悬停约 600ms 自动展开。
  窗口拖到窗口行 = 降级为子组（无跨窗口合并）。
- **搜索**：顶部输入框实时过滤，保留祖先链；离线窗口淡色标记，悬停提示「未绑定浏览器窗口，双击其下标签会新建窗口」。
- **统计底栏**：窗口 / 分组 / 标签 / 已打开四项实时刷新。

## 3. 搜索定位

- 搜索框输入关键词过滤树；方向键在可见标签间移动选中。
- **定位当前标签**（Ctrl+L / ⌖）：按 tabId 反查树内节点并滚动定位；定位前同步真实快照补游离标签；
  当前网页是浏览器内部页（chrome:// 等）时明确提示无法精确定位。

## 4. 快捷键

| 快捷键 | 动作 |
| --- | --- |
| ↑ / ↓ | 选择上 / 下一个可见标签 |
| Enter | 打开选中标签 |
| Delete | 移入回收站 |
| Ctrl+C | 复制选中项 |
| Ctrl+L | 定位当前标签 |
| Ctrl+E | 展开 / 折叠全部 |
| Ctrl+Shift+L | 链接显隐 |
| Ctrl+O | 打开选中分组全部标签 |
| Ctrl+D | 切换深 / 浅色主题 |
| Ctrl+Backspace | 打开回收站弹窗 |

完整表见页内「快捷键」弹窗（三宿主一致）；输入框聚焦时不触发快捷键。

## 5. 主题与外观

- 深 / 浅色主题：快捷栏 ◐ 或设置「外观」分类；选择持久化并对所有宿主广播。
- 链接显隐、复制格式等外观项均在设置面板单击行即时保存。

## 6. 回收站

1. **删除入站**：删除叶子时先按 tabId 关闭真实网页，成功后条目入回收站；删除分组 / 窗口会关闭整棵子树的网页。
   网页关闭失败时不入回收站并给出提示；标签本身已不存在则照常入站。
2. **条目清洗**：入站条目清掉 tabId / open / windowId 绑定——恢复后是离线整理数据，不会绑回已关闭的标签。
3. **恢复**：回收站弹窗（🗑 或 Ctrl+Backspace）内「恢复」→ 节点回到原父容器与原序位；原父已删除则落到首个可用分组或新建默认分组。恢复**不自动重开网页**，需要时双击打开。
4. **彻底删除**：条目永久移除，不可恢复。角标显示条目数。

## 7. 置顶小窗（PiP）与多宿主

- 独立窗口页点 📌（或 Ctrl+P）打开 Document Picture-in-Picture 置顶浮窗：迷你树，点击条目跳转对应标签页，再次点击取消置顶（Chrome ≥ 116，低版本提示）。
- PiP 与主页面共享同一套控制器：设置、回收站、编辑、新建、备份、导入导出均可在 PiP 内操作；toast / 主题广播所有宿主。
- 深度配置（GitHub 授权等受浏览器约束的弹窗）建议在独立窗口操作。
- 点 ◷ 打开浏览器历史页（历史跳转）；点击 ⛶ 提示「全屏卡片视图待实现」（该能力尚未交付）。

## 8. 异常恢复

1. 误删 → 回收站恢复（第 6 节）。
2. 树数据损坏 / 误导入 → 恢复最近的本地快照（备份列表按时间倒序，详见备份指南）。
3. 无快照 → 导入事先导出的 JSON / HTML 备份文件。
4. 扩展重装后数据随浏览器档案的 `chrome.storage.local` 存续；跨设备迁移用导出 JSON 或加密备份。
